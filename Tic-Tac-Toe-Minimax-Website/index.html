Tic-Tac-Toe-Minimax

A basic tic-tac-toe game for the terminal, written in Python with the standard library only. Play against a friend on the same keyboard, or against the computer at two difficulties: a casual mode that plays a fair game, and a hard minimax mode that has already walked every branch of the tree, so the last empty square is a choice among losses.

Open the repo The tests

Run it

python3 tic_tac_toe.py # asks which mode you want
python3 tic_tac_toe.py --pvp # two human players
python3 tic_tac_toe.py --cpu # you are X, computer is O
python3 tic_tac_toe.py --cpu --hard

Requirements: Python 3, standard library only, nothing to install. --hard belongs only beside --cpu: combining --hard with --pvp is rejected with an argparse error and exit status 2.

The board

123456789

Cells are numbered 1 to 9 as shown. Type the number of the cell you want. An entry that is not a number from 1 to 9, or a cell that is already taken, is rejected with a message and the same player is asked again. At the mode prompt, enter 1 for two players, 2 for the computer, or q to quit; anything else prints Please enter 1, 2, or q. and asks again. A running score (X wins, O wins, draws) is kept across rounds.

The two difficulties

Casualtakes wins, blocks losses, prefers the center, otherwise plays a random free cell.
Hardminimax play, unbeatable: an exhaustive game-tree check following the computer's moves found 0 human wins.

Leaving a game

After each game the score is printed and you can play again with y; any other answer ends the session and prints the final score. Closing input (EOF) or pressing Ctrl-C at a move prompt abandons the current game without changing the score, and EOF or Ctrl-C at the mode or play-again prompt ends the session. Exit status is 0.

The tests

python3 -m unittest

32 tests: every win line for both marks, the win-on-the-last-move rule, the casual computer's win, block, and center order, an exhaustive game-tree walk proving the hard computer never loses as X or as O, move entry (including the superscript character that passes isdigit() but crashes int()), scripted games and menu sessions, and EOF and Ctrl-C at each prompt.

The files

tic_tac_toe.py, the whole game. test_tic_tac_toe.py, the test suite. LICENSE, the MIT license. The full behaviour notes are in the repo README.
