Tic-Tac-Toe-Minimax

Patrol log, night entry. A terminal Tic-Tac-Toe game in Python 3, standard library only, in the single file tic_tac_toe.py. Cells are numbered 1 to 9 as printed on the board.

Open the repo The two tempers

Entry: modes

Sharing a keyboard, or facing the machine

Two people can share one keyboard:

python3 tic_tac_toe.py --pvp

Against the machine, the visitor plays X and always moves first, while the computer answers as O:

python3 tic_tac_toe.py --cpu
python3 tic_tac_toe.py --cpu --hard

Seized goods tag: --hard is allowed only beside --cpu. Pairing it with --pvp is refused by argparse with exit status 2.

Entry: tempers

Casual and hard, stated honestly

Casual play takes a winning cell when one exists, blocks the human line when that is urgent, prefers the centre afterwards, and otherwise chooses a free cell at random.

Hard play searches the whole game tree with minimax scored only as win, draw, or loss, worth 1, 0, and minus 1, with no bonus for winning sooner, then picks at random among the moves tied for best. Hard games vary while never losing. The proof offered by the tests: an exhaustive walk found zero human wins, and the full suite counts 32 tests run with python3 -m unittest.

Entry: table manners

How the program behaves at the board

A mistyped or occupied cell is rejected and the same player is asked again. The score for X wins, O wins, and draws carries across rounds. Only a plain y starts another round.

Seized goods tag: Ctrl-C or closed input at a move abandons that game with no score change.
